# لا تكن إسفنجة! 🧽

تجربة تفاعلية لأطفال الروضة (٤–٦ سنوات): إسفنجو يكتشف أن الإسفنجة تمتص كل شيء… لكن الإنسان يختار.
القيم: ﴿وَقُولُوا لِلنَّاسِ حُسْنًا﴾ · «فليقل خيرًا أو ليصمت» · «لا تغضب».

- **العرض:** افتحي الصفحة ← «ابدئي العرض» (يفضَّل Chrome وملء الشاشة).
- **التحكم:** مسافة/→ التالي · ← السابق · ١/٢ اختيار الأطفال · R إعادة اللحظة · M الصوت · P نافذة المقدِّمة.
- **دليل المقدِّمة (PDF):** [guide.pdf](guide.pdf)

يعمل بدون إنترنت أيضًا: نزّلي المستودع (Code ← Download ZIP) وافتحي `index.html`.
